\doxysubsection{Detailed Description}
Thread-\/safe queue that never allows old samples to block live acquisition. 

When full, discards the oldest \doxylink{class_generic___d_s_o___single___file_071_08_1_1_frame}{Frame} rather than metadata or error events, and marks the subsequent retained frame with {\ttfamily gap = True}.
