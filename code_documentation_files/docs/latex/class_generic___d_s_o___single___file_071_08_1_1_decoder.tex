\doxysubsection{Detailed Description}
Stateful JSON-\/line protocol v1 parser and continuity validator. 

Validates \textquotesingle{}hello\textquotesingle{}, \textquotesingle{}status\textquotesingle{}, and \textquotesingle{}samples\textquotesingle{} packets, enforces monotonic sequence numbers and timestamps, and detects sample dropouts/\+gaps.
